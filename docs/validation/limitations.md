# 当前限制与验收边界

代码实现：任务级分布式小模型推理、任务租约/恢复、机主控制、缓存与积分、真实报告和基准脚本。

自动化协议测试的模型替身只在 tests/ 中。正式 Worker 调用原生 llama.cpp，不使用远程 API 或固定答案回退。

尚需真实设备完成的事项：

- Windows CPU / CUDA 真实20题与可执行包依赖核对。代码有跨平台启动/终止分支，当前可访问验证机为 Mac。
- 最低8GB Mac的10分钟正常工作体验、内存压力与机主反馈。当前本机是16GB Apple M1 Pro，不能代替此项。
- 多台物理电脑的实际分配、真实网络失联与备用网络恢复。
- 两组各三次的性能对照。没有真实多机数据就没有加速倍率结论。
- 一位潜在使用者的需求反馈，以及两次三分钟计时演练/备份录像。

一台机器上启动多个协议测试客户端可以验证竞争，但不算多台物理设备，不作为性能证据。控制档位改变工作间隔，不是准确的 GPU 使用率限制；后台推理仍消耗电力。

安全范围是受信任的小组。用户题目会发到贡献节点，当前没有陌生节点防作弊、账号/付费体系、多协调器高可用。贡献端需要原生引擎及固定模型，浏览器本身不执行模型。

本机启动时生成的 config/local-*.json 含加入码或个人路径，不提交、不随报告分享；runtime.lock.json、数据清单和脱敏的实际报告可以分享。
